# Design Gate

For any NEW feature (not bug fixes), nothing gets built until this passes:

1. **Plain language description** — what the feature does and why, no code/jargon.
2. **Rough sketch** — a rough mock of layout or flow, meant to surface related
   ideas or missing pieces before code exists, not a pixel-perfect design.
3. **Explicit sign-off** — Norm reviews and approves before any building starts.

Bug fixes skip this gate and go straight to Process Guardrails.
